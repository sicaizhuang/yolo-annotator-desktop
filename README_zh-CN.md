# YOLO Annotator Desktop

一个快速、离线优先、无需 Docker 的 YOLO 矩形框桌面标注软件。

它来源于真实的元器件识别与抓取项目，目标是让人工审核过程足够顺手，
同时尽量避免类别 ID、自动保存和数据导出造成的隐蔽错误。

## 主要功能

- 左键拖动框选，点击选择，拖动控制点调整框。
- 自动保存、撤销/重做、滚轮缩放、右键拖动画面、隐藏标签。
- 跳转指定图片，一键前往下一张未审核图片。
- 使用 `.yad.json` 保存项目路径和配置。
- 安全添加、改名、删除、排序类别；修改前自动备份标签并重映射 ID。
- 检查非法标签、越界框、孤立标签、重复图片名等问题。
- 自动划分训练集/验证集，并导出标准 YOLO `data.yaml`。
- 完全本地运行，不上传图片。

## Windows 使用

双击 `run_windows.cmd`。首次运行会创建本地虚拟环境并安装 Pillow。

进入软件后：

1. 点击 `New Project` 创建新项目，或点击 `Open Project` 打开 `.yad.json`。
2. 将图片放入项目的 `images` 目录。
3. 点击 `Open Annotator` 开始框选。
4. 点击 `Run Quality Check` 检查数据。
5. 点击 `Export YOLO Dataset` 导出可训练数据集。

## 常用操作

| 操作 | 按键 |
|---|---|
| 绘制框 | 在空白区域按住左键拖动 |
| 选中框 | 左键/右键点击框，或点击右侧列表 |
| 调整框 | 拖动选中框周围的白色控制点 |
| 缩放/平移 | 滚轮 / 按住右键拖动 |
| 上一张/下一张 | `A` / `D` 或方向键 |
| 下一张未审核 | `U` |
| 修改选中框类别 | 选择类别后按 `C` |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Y` |
| 隐藏标签 | `H` |
| 删除选中框 | `Delete` |

类别管理会在修改 ID 前完整备份标签目录；导出数据集不会修改源数据。
