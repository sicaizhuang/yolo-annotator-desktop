# YOLO Annotator Desktop

一个快速、离线优先、无需 Docker 的 YOLO 桌面标注软件。

它来源于真实的元器件识别与抓取项目，重点是标注手感、数据安全和低学习成本。

## 主要功能

- 普通矩形框和三点式旋转矩形框。
- 旋转框保存为标准 YOLO OBB 四角点格式。
- 自动保存、撤销/重做、滚轮缩放、右键拖动画面、隐藏标签。
- 可在标注界面随时添加自定义类别。
- 安全添加、改名、删除、排序类别；修改前自动备份并重映射类别 ID。
- 可新建空数据集、接管已有图片/标签目录，或从 YOLO `data.yaml` 导入。
- 检查非法标签、越界框、孤立标签、重复图片名等问题。
- 检测普通框与 OBB 混用，并阻止导出通常无法直接训练的数据集。
- 自动划分训练集/验证集，并导出标准 YOLO `data.yaml`。
- 完全本地运行，不上传图片。

## Windows 使用

双击 `run_windows.cmd`。首次运行会创建本地虚拟环境并安装依赖。

打开已有 `.yad.json` 项目时会直接进入标注工作区。需要新建或导入数据集时，启动软件但不指定项目，即可进入项目中心。

## 常用操作

| 操作 | 按键 |
|---|---|
| 普通矩形框模式 | `B` 或工具栏 `□` |
| 三点式旋转框模式 | `R` 或工具栏 `↔` |
| 绘制普通框 | 按住左键拖动 |
| 绘制旋转框 | 拖出第一条边并松开，移动鼠标确定宽度，再单击完成 |
| 选中框 | 左键/右键点击框，或点击右侧列表 |
| 调整普通框 | 拖动选中框周围的白色控制点 |
| 缩放/平移 | 滚轮 / 按住右键拖动 |
| 上一张/下一张 | `A` / `D` 或方向键 |
| 下一张未审核 | `U` |
| 修改选中框类别 | 选择类别后按 `C` |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Y` |
| 隐藏标签 | `H` |
| 删除选中框 | `Delete` |

类别管理会在修改 ID 前完整备份标签与类别文件；导出数据集不会修改源数据。
