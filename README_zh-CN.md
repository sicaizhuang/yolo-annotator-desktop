# YOLO Annotator Desktop

一个快速、离线优先、无需 Docker 的 YOLO 桌面标注软件。

它来源于真实的元器件识别与抓取项目，重点是标注手感、数据安全、低学习成本和标准格式兼容。

## 主要功能

- 完全本地运行，不需要浏览器、账号、数据库或服务器。
- 可搜索、可筛选的图片列表，区分未审核、已标注和已确认空图。
- 普通框和三点式旋转框；支持选择、移动、拉伸、微调、复制、粘贴、改类别和删除。
- 旋转框保存为标准 YOLO OBB 四角点格式，并可拖动角点保持矩形形状。
- 自动保存采用原子写入；提供撤销/重做、会话备份、陈旧项目锁回收和错误日志。
- 遇到异常标签行时保留原始内容，不会在编辑后悄悄丢失。
- 支持便携 `.yad.json` 项目和嵌套图片/标签目录。
- 可新建数据集，或从已有目录、YOLO `data.yaml`、COCO JSON、Pascal VOC XML 导入。
- 可导出 YOLO 训练/验证集、COCO JSON 和 Pascal VOC XML。
- 质量检查覆盖损坏图片、非法几何、类别错误、格式混用、重复框、重复图片、孤立标签和未使用类别。
- 类别管理支持添加、重命名、删除、排序；修改 ID 前会完整备份并安全重映射。
- 支持 JPG、JPEG、PNG、BMP、WebP、TIF 和 TIFF。

## Windows 使用

双击 `run_windows.cmd`。首次运行会创建本地虚拟环境并安装依赖。

首次运行完成后，可双击 `launch_windows.vbs` 静默启动。运行一次 `create_desktop_shortcut.cmd` 可以创建桌面快捷方式。

也可以直接打开指定项目：

```powershell
.\.venv\Scripts\python.exe -m yolo_annotator_desktop path\to\project.yad.json
```

## 常用操作

| 操作 | 按键 |
|---|---|
| 选择并移动框 | `V`，然后拖动框 |
| 绘制普通框 | `B`，按住左键拖动 |
| 绘制旋转框 | `R`，拖出第一条边，松开后移动鼠标确定宽度，再单击完成 |
| 调整选中框 | 拖动白色控制点 |
| 微调选中框 | 方向键；按住 `Shift` 每次移动 10 像素 |
| 复制 / 粘贴 / 偏移复制 | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| 缩放 / 平移 | 滚轮 / 按住右键或中键拖动 |
| 上一张 / 下一张 | `A` / `D` |
| 下一张未审核 | `U` |
| 标记为空图并完成审核 | `N` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 隐藏或显示标签 | `H` |
| 保存 | `Ctrl+S` |
| 删除选中框 | `Delete` |

## 数据安全

标签、项目、偏好和报告使用原子写入。每次会话首次修改某个标签前会自动创建恢复副本。类别 ID 修改前会完整备份。导出不会修改源图片或标签，也不允许把导出目录放进源图片或标签目录。
